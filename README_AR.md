# SQ Motion Studio — نسخة KlenCod (Java + JavaScript)

مشروع Android يستخدم Java في MainActivity وواجهة المحرر بـ HTML/CSS/JavaScript داخل WebView.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `SQMotionStudio_KlenCod_JavaScript` نفسه في KlenCod IDE، وهو المجلد الذي يحتوي على `settings.gradle`.
3. اسمح بمزامنة Gradle إذا طلب تنزيل الأدوات، ثم جرّب Build APK.

## تنبيه
هذه نسخة أولية بواجهة محرر وحركة وعناصر تفاعلية من JavaScript، وليست نسخة مطابقة بالكامل لتطبيق KeyFlow. بعض عمليات تصدير الفيديو قد تعتمد على دعم WebView في جهازك. لم أتمكن من تشغيل بناء Android هنا، لذلك لا أستطيع ضمان نجاح البناء في كل نسخة من KlenCod.
